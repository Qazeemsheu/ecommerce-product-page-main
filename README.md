# E-commerce Product Page

A responsive product page built with HTML, CSS and vanilla JavaScript. This project is based on the [Frontend Mentor E-commerce product page challenge](https://www.frontendmentor.io/challenges/ecommerce-product-page-UPsZ9MJp6).

## Features

- Responsive layout for desktop, tablet and mobile screens
- Product image gallery with selectable thumbnails
- Desktop image lightbox with previous and next controls
- Mobile image navigation
- Mobile navigation drawer
- Quantity selector with a minimum value of zero
- Shopping cart with item count, calculated total and remove action
- Empty-cart state
- Keyboard support for closing overlays and navigating the lightbox

## Built with

- Semantic HTML5
- CSS custom properties and responsive media queries
- Vanilla JavaScript

## Getting started

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No package installation or build step is required.

## Notes

The checkout button is a demonstration control. This frontend project does not process payments or store orders.
